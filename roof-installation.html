What to ask

Installation requests should define the full roofing system.

Before comparing installation providers, ask how they explain material choice, underlayment, flashing, ventilation, fastening method, permits, and project timeline.

A clearer request should separate roof system planning from surface-level price only, so you can compare what each provider includes before choosing.
